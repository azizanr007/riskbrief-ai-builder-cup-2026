# Genuine screen recording script — under three minutes

Capture only after a real authorized Firebase deployment and verified Gemini response exist. This is a recording script, not footage or proof of model use. Hide passwords and credentials; use provisioned demo accounts and only the bundled synthetic input. Record actual success or actual errors. Do not splice mock output into the model sequence.

| Time | Actual screen action | English narration/caption |
|---|---|---|
| 0:00–0:15 | Open the actual verified HTTPS deployment URL | “RiskBrief demonstrates evidence-led BFSI triage using synthetic aggregate data and a separate human review.” |
| 0:15–0:35 | Sign in using a provisioned analyst account; hide credential entry | “Access is provisioned. This prototype does not accept real customers or financial decisions.” |
| 0:35–1:00 | Load the synthetic example and run deterministic analysis | “Fixed illustrative thresholds calculate the indicators. These evidence IDs and the input hash identify what was computed.” |
| 1:00–1:35 | Make one actual Gemini request; record its real returned outcome | “Firebase AI Logic sends compact synthetic evidence to Gemini. The model can select supported findings but cannot create new measurements or execute actions.” |
| 1:35–1:55 | Show successful evidence validation, uncertainty and real usage metadata if returned | “Unknown citations and unsupported findings are rejected. Synthetic-data, calibration and human-review limitations remain visible. Usage is shown only when actually reported.” |
| 1:55–2:10 | Save the brief and retrieve it from Firestore | “The brief is saved with its evidence, source model and pending decision.” |
| 2:10–2:35 | Sign out; sign in as a separately provisioned active reviewer, hiding credentials; decide once | “An authorized human reviewer independently approves or rejects the pending brief.” |
| 2:35–2:50 | Show final status, audit event and actual source repository | “The review state and append-only client event are visible. This static demonstration is not a production financial adjudication system.” |

If the verified provider returns an error or quota denial, retain that result and do not describe the recording as a successful Google AI demonstration. The video must be accessible to judges without requesting permission and match the authenticated dashboard's length requirement.
